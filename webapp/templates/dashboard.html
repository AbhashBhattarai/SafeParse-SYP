SafeParse — Memory-Safe C Parser Generator

SafeParse is a compiler that takes a binary format specification and generates bounds-checked C parsers in two variants: a straightforward naive parser with per-field checks, and an optimized parser that batches contiguous fixed-size fields into a single upfront bounds check, reducing branch overhead without sacrificing safety. The tool targets embedded and systems developers who need to parse untrusted network or file data without manual buffer-arithmetic errors.
